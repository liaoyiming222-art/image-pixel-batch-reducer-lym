# 节约时间统计：方案与验收

基于 `9fd466f`（多目录图片搜索）实现。保留原有产品总览，新增 `/admin?view=savings` 页面，按站点隔离。

## 估算模型

| 功能 | 原流程初值 | 工具流程估值 | 单位 |
|---|---:|---:|---|
| 图片压缩 | 30.0 秒 | 3.0 秒 | 一张实际压缩或转换成功的图片 |
| 比例检测与分组 | 70.0 秒 | 2.0 秒 | 在比例工具中完成检测并生成分组的一张图片 |
| AI 需求目录 | 90.0 秒 | 5.0 秒 | 一组完整新建的主目录及 AI、原图子目录 |
| 图片搜索与匹配 | 120.0 秒 | 3.0 秒 | 一张已成功匹配、歧义已选定的图片 |

原流程初值来自用户测试。工具流程时间是可校准的产品估值，考虑批量操作中选择文件、设置参数、等待结果的分摊；不是机器运行时间或人工实测结果。设备、文件大小、批量大小会改变实际时间。

预计节约秒数 = 完成单位数量 ×（原流程秒/单位 − 工具流程秒/单位）。四个步骤分别估算并加总，可能存在步骤重叠，不能当作实际净节省人力工时。以整数十分之一秒计算，避免小数累积误差。新流程更慢时保留负值，不截断为零。

## 页面和参数

- 累计节约、本期节约、本期提效比例；四张工具卡同时展示可编辑时间、单位节约、本期数量、本期与累计节约。
- 日期筛选作用于本期，累计始终独立；自然月表展示各工具及合计。
- 输入支持 0–86400 秒、最多一位小数。修改即时预览，点击保存后跨设备读取。未保存的草稿不会被自动刷新覆盖。
- 当前参数重算全部历史估算，页面明确标注。保存按站点独立，修订号防止并发编辑覆盖；自动读取期间仍保留开始编辑时的修订号。
- 事件入库即可参与下一次读取计算，不等待每日汇总。沿用看板每十分钟自动读取、切回页面读取及手动立即刷新；因此自动展示并非逐秒刷新。

## 埋点批次

新增 `time_saving_completed`，工具为 compress / inspect / folders / finder，属性只有正整数 count，任务编号必需。重用同源接口、事件编号去重、站点校验、限流和管理员鉴权，不上报文件名、路径、图片、图名、需求名称。

- 压缩：压缩工具与分组下载实际转换成功后计数；跳过和失败不计，重新运行成功是新操作。
- 检测：进入比例工具完成尺寸比例与分组即计数；与全站“服务图片数”独立，同一队列跨工具、改设置不重复，新导入图片有新编号。
- AI 目录：只在完整新建一组后计一次，不将三个实际目录乘三；已有、补齐、失败和普通目录不套用 90 秒初值。原目录数量指标仍保留实际创建数。
- 查找：自动唯一匹配或人工确认歧义后计入，同一清单同一图片仅一次；反复查找、重新选择同一结果不重复。重新提取/清空清单开启新计数。

2026-10-21 更新：新增事件之外，回溯实际压缩成功数、比例工具的检测数，以及 mode=aigc 且无失败批次的 created 主目录数量。压缩工具的宽泛服务图片量、普通目录、含失败 AI 批次和未记录的历史搜索不补算。同一会话、同一天、同一功能的新旧来源取较大值而非相加，避免重复，但混合使用旧版本时可能保守低估。开始时间取最早可确认有效记录；暂无记录时累计、本期明确显示 0.0 秒。

## 实施批次与本地验收

1. 数据层：`0003_time_savings.sql` 增加站点参数表；GET/PUT 管理接口与共享计算模型。
2. 应用层：四个工具补齐有效用量事件；新增独立节约时间页和编辑、保存、月度计算。
3. 验收：类型检查、自动测试、生产构建；隔离的本地 D1 + Pages Functions 运行实际浏览器流程。

本地完整验收覆盖：一张 PNG 转 JPG、进入/重返比例工具、完整创建 AI 目录、重复创建跳过、部分失败、歧义匹配后重试。四个有效用量均为 1；参数从 3.0 改为 4.0 后重开页面保持；手机无页面横向溢出、无脚本错误。本地目录使用内存文件系统模拟，测试没有写入线上库。

发布前在生产 D1 应用新增迁移，再推送 GitHub 触发两个站点部署。迁移仅增加参数表，旧数据和旧看板不受影响。线上回归只做读取与资源检查，不写入测试事件。

## 匿名用户（2026-10-21）

产品总览右侧优先显示期间匿名访问用户数，月度表各月分别去重。复用 events.user_id，不新增身份采集、不按 IP 合并；同一浏览器重复访问去重，隐身、换设备、清除存储会产生新编号。统计期间有访问或工具行为的浏览器，不能代表真人数量；月度去重人数不可相加为累计。

新增 /api/admin/users 管理员读取接口和匿名用户页，每页 20 位。展示期间访问量、会话、服务图片、压缩成功、主子目录及已记录匹配量；匿名标签由站点与原始编号散列生成，不返回原始 user_id。不上传或展示文件名、路径、姓名等信息。已有埋点和索引足够，无新增数据库迁移。

108 项测试、前后端类型检查、构建及隔离本地浏览器验收通过。使用模拟的 151 张压缩成功、43 张比例检测、17 组完整 AI 目录，默认参数得到 8446.0 秒（约 2.3 小时）；21 位模拟用户验证去重和分页。测试未向线上写入业务事件。
