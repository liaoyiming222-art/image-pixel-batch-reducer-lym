# AI 本地图片与文件工具箱

一个使用 React、TypeScript 和 Vite 构建的纯前端工作效率工具箱。统一提供图片大小压缩、图片尺寸与画幅比例检测，以及 AI 需求文件夹批量创建功能。

## 功能

### 图片大小压缩

- 点击、拖拽或按文件夹批量导入 JPG、JPEG、PNG、WebP
- 显示文件大小、像素尺寸和宽高比
- 支持仅处理超限图片或处理全部图片
- 自定义平台限制与目标大小，优先降低像素并保持宽高比
- 支持单张下载和保留目录结构的 ZIP 下载

### 图片尺寸提取

- 批量读取 JPG、PNG、WebP、GIF、BMP 的宽高、方向和文件大小
- 计算实际比例，匹配最接近的标准画幅比例并显示误差
- 支持排序、去重、删除、汇总统计和清空
- 支持复制全部结果和导出带 UTF-8 BOM 的 CSV

### 文件夹批量创建

- 解析从 Excel / WPS 复制的多行 TSV 数据，包括单元格内换行
- 从需求说明自动提炼命名后缀并生成统一文件夹名称
- 支持编辑后缀和最终名称，记住常用自定义后缀
- 在用户授权的本地位置批量创建文件夹，同名文件夹自动跳过

## 本地启动

```bash
npm install
npm run dev
```

## 测试与构建

```bash
npm run test
npm run build
```

构建结果输出到 `dist`。

## 隐私说明

图片、表格内容和文件夹信息只在浏览器本地处理，不会上传到服务器或第三方接口。直接创建文件夹功能需要最新版 Chrome 或 Edge，并且只会访问用户主动授权的目标目录。

## Vercel 部署

项目是标准 Vite 静态前端：Build Command 使用 `npm run build`，Output Directory 使用 `dist`。也可以在已关联项目的目录中运行：

```bash
npx vercel --prod
```
