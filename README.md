# 图片像素批量降低工具

一个基于 React、TypeScript 和 Vite 的纯前端图片批量处理工具。用于在上传 AI 平台前检查图片大小，并通过优先降低像素尺寸的方式，将超限图片处理到指定目标大小以下。

## 主要功能

- 点击选择或拖拽导入多张 JPG、JPEG、PNG、WebP 图片
- 展示文件名、格式、文件大小、像素尺寸和宽高比
- 支持“仅处理超限图片”和“处理全部图片”两种模式
- 自定义平台限制、目标大小和输出质量
- 通过逐步缩放和二分查找降低像素，保持原始宽高比
- 正确读取 EXIF 方向，保留 PNG 格式和透明背景
- 限制批处理并发，单张失败不会影响其他任务
- 显示处理进度、新尺寸、新大小和减少比例
- 支持单张下载，以及 ZIP 打包下载全部结果

## 本地启动

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

Vite 默认会提供一个本地访问地址，通常为 `http://localhost:5173`。

## 构建与测试

```bash
npm run test
npm run build
```

生产构建结果会输出到 `dist` 目录。

## 隐私说明

所有图片均只在用户浏览器本地读取和处理，不会上传到服务器或任何第三方接口。刷新或关闭页面后，已选择的图片和处理结果不会被保留。

## 部署到 Vercel

该项目是标准 Vite 单页前端，可直接部署到 Vercel：

1. 将项目推送到 GitHub。
2. 在 Vercel 中导入对应 GitHub 仓库。
3. Framework Preset 选择 `Vite`。
4. Build Command 使用 `npm run build`。
5. Output Directory 使用 `dist`。
6. 完成部署后，Vercel 会提供公开访问地址。

项目不需要后端服务、数据库或运行时环境变量。
